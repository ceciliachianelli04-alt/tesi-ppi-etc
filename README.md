# tesi-ppi-etc

# Reti PPI 

Codici Python sviluppati per la tesi di laurea triennale
*"Reti di interazione proteina-proteina della catena di trasporto degli elettroni
mitocondriale: analisi e validazione computazionale"*
— Cecilia Chianelli, Università Campus Bio-Medico di Roma, a.a. 2025/2026.

## Struttura del repository

- **`reti etc/`** – codici per la costruzione delle reti PPI limitate alle sole proteine della catena di trasporto
  degli elettroni (ETC), una per ciascun database.
- **`reti estese/`** – codici per la costruzione delle reti estese: ETCEST, NEURO, NEUROESTBIO, NEUROESTETC.
